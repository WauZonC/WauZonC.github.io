液态玻璃：参数与观感

本页的玻璃材质来自 liquid-glass.css（原生 CSS，零依赖、零脚本、零外部请求）。 要看「装在真实首页上是什么样」，请打开 real-home.html； 要看「和现在的毛玻璃差多少」，请打开 real-home-plain.html 对照。

先读这一条，否则容易误判： 折射只有在玻璃背后有高频细节（文字、条纹、图片边界）时才看得见。 本站背景是平滑的多层柔光渐变，在纯背景区域，液态玻璃和现在的毛玻璃几乎看不出差别—— 这不是没生效，而是没有可折射的东西。下面第一组图就是为了说明这一点。

一、同一块玻璃，压在四种不同频率的底上

四格的玻璃完全一样（都是 .lg .lg-refract .lg-panel），只有背后的内容不同。

二、四层材质，逐层叠出来的效果

真正让观感像 iOS 26 的主要是后三层，而不是折射；这也是为什么在不支持真折射的浏览器上它不会塌。

三、面板 / 卡片 / 药丸 三个角色的差异

面积越小，折射要越收敛，否则小控件会显得「脏」。目前三种角色的参数在下表。

四、参数速查

单位都在 SVG 的 feDisplacementMap scale 上（像素量级），贴图尺寸是该角色「烘焙时的名义尺寸」。

角色 名义尺寸 圆角 rx 边缘厚度 depth 位移 scale 色散级差 用在哪
.lg-header 1280 × 58 0 8 26 3 sticky 页头

想改这些数字：它们不是 CSS 变量，而是烘焙进 data URI 的 固定值（这是「零 JS」的代价）。改动方式是调 tmp/gen_lg_maps.py 里的 ROLES 字典重新生成 liquid-glass.css，不要手改那一长串 base64/百分号编码。
