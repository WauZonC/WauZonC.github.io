课上有教学班的进度，自学可以按自己的节奏走。我主要按 CS61A → CS61B → CSAPP（15-213）的顺序推进，这里记一下顺序背后的理由和几条做法。

## 顺序

- **CS61A（SICP）**：用 Python 讲编程范式与数据抽象。放在最前面，是因为它训练的是「怎么把问题拆成函数和数据」，后面的课都要用。
- **CS61B**：数据结构与算法，用 Java 实现基础 ADT、图与排序。语言基础有了之后，这门课的作业量最大，收获也最直接。
- **CSAPP（15-213）**：从 C 一路看汇编、缓存、链接、并发，把「程序在机器上到底怎么跑」讲清楚。放在后面，是因为它反复用到前两门课的东西。

## 做法

1. **以作业驱动，而不是以视频驱动**：先把作业题读懂，缺什么再回去查，比按顺序看完所有讲义效率高。
2. **写完必须跑测试**：课程给的测试只是下限，我会自己补几个边界用例，比如输入为空、只有一个元素。
3. **卡住时先写下当前假设**：把「我以为哪里有问题」写下来再动手改，能避免无目的地改代码。
4. **做完回头看别人的实现**：不是为了抄，而是看别人怎么组织代码。

## 一个具体的例子

CS61B 的 Proj 3 是用 Java 写一个迷宫游戏引擎，从伪随机地图生成到存档读写都要自己实现。做完之后，我对「把一个大作业拆成可测试的小模块」有了实感——那也是我第一次认真写单元测试。

实现放在课程的作业框架里：<https://github.com/WauZonC/CS61B-sp24-sol/tree/main/proj3>

## 一点提醒

课程的材料（讲义、作业框架、测试）版权属于原课程，公开时要注意边界：**不要把题解、作业答案当成自己的作品发布**，也不要把 fork 来的课程骨架仓库挂在主页上当项目。我现在更倾向于——只公开自己真正写出来的东西，作业框架照实说明来源。
