课上有教学班的进度，自学可以按自己的节奏走。我主要按 CS61A → CS61B → CSAPP（15-213）的顺序推进，这里记一下顺序背后的理由和几条做法。

## 顺序

- **谭浩强《C程序设计》**：我的入门书，其实是在学习巅峰的高三暑假硬啃下来的，据说这本书在使用它作为教材的大学风评很差，但是稚嫩的我怎么会知道如何评价好坏呢，遂读完（
- **CS61A（SICP）**：用 Python 讲编程范式与数据抽象。这是我迈入自学的第一门课程，也是第一门真正意义上看完读完做完的课程，听感很不错，尤其是SICP中很多内容对我当时在学的计算概论A实验班有很大启发。记得当时我做完最后一个作业之后还激动地给这门课UCB的讲师写邮件感谢来着，最终也是石沉大海...
- **CS61B**：数据结构与算法，用 Java 实现基础 ADT、图与排序。学完这门课我最熟悉的语言就从C++变成了Java，当然现在Java也已经非常不熟练了（可能也不需要熟练了），大作业我用了一整周从零开发算法、生成逻辑，以后有机会一定研究资料好好讲讲这一块。
- **CSAPP（15-213）**：四大礼包第一门，在大一寒假就开始自学了，但是两位年事已高的老师讲的课实在太干了，听不动，只好放到大二上这门课的时候再听，虽然依旧是对着PPT自学（

## 做法

AI 生成了很多圣人做法，全删掉了，我的做法其实很简单，就是先在B站找课上，再下载作业自己写，有问题问AI，所有提问尽量记录下来成为非常有效的笔记。
